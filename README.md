Entry for the [The Robot Apology bounty](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59) on make.fun.

A robot apologizes for watering the wrong plant — a drowned orchid, a mixed-up pot — and promises to read the labels before it pours from now on.

## Run

```sh
node main.ts
```

Writes the two-line apology to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
